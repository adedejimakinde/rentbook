# Design reference

Approved designs for the public site and owner dashboard. Build to match these.

- DESIGN-SYSTEM.md: brand rules, components and motion (the source of truth).
- tokens.json: colours, type scale, spacing, radius and shadows.
- *.png: the approved phone designs (390px wide).
- *.html: static HTML of each design for exact sizes, colours and spacing. Placeholders in [BRACKETS] and "Photo: ..." labels are filled from the database and uploaded images.

Pages: HomeV2 (home), CatalogueV2 (rentals list), ItemV2 (item detail), CartV2 (cart), AdminDashboardPhone (owner dashboard on phone).
